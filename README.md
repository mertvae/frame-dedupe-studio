# Frame Dedupe Studio

Программа для пакетного удаления повторяющихся кадров из анимации и подготовки видеодатасетов. Работает локально на Windows через Python, Tkinter и FFmpeg. Поддерживает MP4, MOV и MKV. В интерфейсе можно сравнить исходник с результатом, проверить количество кадров и сохранить отдельные ролики или весь батч.

## Установка на Windows

1. Скачайте проект через **Code → Download ZIP** и распакуйте архив. Откройте PowerShell в папке с файлом **Start_Frame_Dedupe.bat**.
2. Установите Python и полную сборку FFmpeg с проигрывателем ffplay. Если они уже установлены, переходите к проверке.

   ```powershell
   winget install --id Python.Python.3.13 -e
   winget install --id Gyan.FFmpeg -e
   ```

3. Заново откройте PowerShell в папке программы и проверьте доступность инструментов.

   ```powershell
   py -3 --version
   ffmpeg -version
   ffprobe -version
   ffplay -version
   ```

4. Создайте окружение и установите NumPy для адаптивного тайминга. Затем запустите интерфейс.

   ```powershell
   py -3 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install numpy
   .\Start_Frame_Dedupe.bat
   ```

Для последующих запусков дважды щёлкните **Start_Frame_Dedupe.bat**. Если Windows не находит ffmpeg или ffplay, добавьте папку bin из полной сборки FFmpeg в PATH и откройте программу заново.

## Первый батч

1. Нажмите **Добавить файлы…** или **Добавить папку…**. При выборе папки программа читает видео непосредственно из неё.
2. Выберите **Точные подряд** и нажмите **Сканировать батч**. В таблице появится количество кадров до и после обработки.
3. Выделите один ролик и сравните **▶ Исходник** и **▶ Результат**. При визуальном сравнении обратите внимание на моргание, медленные панорамы и намеренно удержанные позы.
4. Нажмите **Сохранить выбранные…** или **Сохранить весь батч…** и укажите отдельную выходную папку.

| Режим | Какие кадры удаляются |
| --- | --- |
| Точные подряд | Соседние кадры с одинаковым хешем декодированных пикселей. |
| Похожие подряд | Визуально близкие кадры по оценке FFmpeg mpdecimate, включая небольшие расхождения после сжатия. |
| Похожие: сильнее | Допускает большие расхождения. Может удалить слабое движение. |
| Все точные | Все точные повторения внутри ролика после первого появления кадра, включая возвраты к прежней позе. |

Удаление повторов сокращает хронометраж. Если из 48 кадров при 24 fps удалить 12, останется 1,5 секунды. Программа вырезает соответствующие интервалы звука. Флажок **Убрать звук из сокращённых видео** позволяет экспортировать сокращённые ролики без аудио. Файлы без повторов копируются целиком. Сокращённое видео кодируется в H.264 без потерь и может занимать больше места, чем исходник.

## Анимация на двойках

Для изменения ритма анимации выберите **Обычные двойки** или **Адаптивные двойки**. На сетке 24 fps обычные двойки удерживают позу два кадра, адаптивные подбирают длительность экспозиции с учётом движения, склеек и акцентов. Кнопки **Карта экспозиций** и **Закрепить кадры…** позволяют проверить распределение удержаний и сохранить важные позы.

## Командная строка

Укажите входную и отдельную выходную папки. Первая команда только считает кадры. Вторая записывает результат.

```powershell
py -3 dedupe_video_frames.py ".\input" ".\output" --mode adjacent --dry-run
py -3 dedupe_video_frames.py ".\input" ".\output" --mode adjacent
```

Параметр `--mode` принимает `visual` (по умолчанию), `strong`, `adjacent` и `all`. Для удаления звука из сокращённых видео добавьте `--drop-audio`. CLI сохраняет исходные имена и сообщает об ошибке, если файл назначения уже существует.
